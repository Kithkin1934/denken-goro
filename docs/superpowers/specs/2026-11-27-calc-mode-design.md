# 計算問題モード（短い設計）

## 目的
計算問題は語呂ではなく計算で解きたい。語呂の復習から外し、計算だけの練習枠で解く。

## 決めたこと（ユーザー）
- 振り分けは **iPad のアプリで手動**。「計算へ移す／語呂へ戻す」ボタンだけ。自動判定・まとめて移動は作らない（対象は簡単な計算問題だけで数が少ない）。

## 私の判断（直せる）
- 印は別テーブル `tags`（cardId, calc, at）に保存。問題データ（zip）を読み込み直しても消えない。バックアップにも入れる（古いバックアップはそのまま読める）。
- ボタンは問題を解く画面の上部。押すとその場で切り替わり、次の出題から反映。
- 「今日の復習」「〇〇の復習」は語呂の問題だけ。科目の欄に、計算問題が1問以上あれば「計算問題（復習 N）」ボタン。理論に限らず全科目で使える。
- 計算モード：語呂は最初は隠し「語呂を見る」で開く。答えたあと「計算で解けた（Good）／自信なし（Hard）」。不正解は Again。20秒の即答判定は使わない。新しい問題の1日上限はかけない（自分で選んだ少数のため）。
- 忘却曲線の状態は語呂と計算で共通（移しても学習記録は引き継ぐ）。
- 問題一覧で計算問題のマスに「計」の印。

## アプローチ
- A. 自動判定＋手動修正 — 不要（数が少ない）
- B. **手動のみ（採用）**
- C. Mac で振り分け — Mac が必要になり不採用
